Top-down zombie survival in a single page. Play it in the browser, or put it on your home screen and it runs with no signal.

On Android

  1. Tap PLAY NOW above. It works immediately in Chrome - nothing has to be installed to play.
  2. To keep it, tap the three-dot menu, top right.
  3. Tap Install app (older Chrome says Add to Home screen), then Install. If the menu has no such entry, reload the page once and open the menu again.
  4. The ROT & RUIN icon appears on your home screen or in the app drawer. Open it from there, not from the browser.
  5. Let the start screen finish drawing once. That is when it caches itself.
  6. Turn on airplane mode and open the icon again. It plays. That is the offline check.
  7. Downloaded the zip instead? Open the Files app, tap the zip once, tap Extract, then open index.html. It plays from the folder - but a page opened as a file cannot cache itself, so it needs no signal only if you use the install route above.

On an iPhone

  1. Open this page in Safari, not Chrome. Safari is the one that does this properly.
  2. Tap PLAY NOW, then the Share button - the square with the arrow coming out of the top.
  3. Scroll the sheet, tap Add to Home Screen, then Add.
  4. Open the icon from the home screen and let the start screen draw once.
  5. Airplane mode on, open it again. That is the offline check.

What is in the zip

The game, the co-op page, the icons and a README.txt with these same steps. Unzipping an iPhone needs no app: tap the zip once in Files and it unpacks beside itself. But Safari will not run the game from Files - the zip is for keeping the files or putting them on your own web server. To play on a phone, use the two paths above.

Co-op needs a room server. The co-op page asks for its address once, then sends a link that puts a friend in your room with nothing to type.
