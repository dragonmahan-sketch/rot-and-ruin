THE ADDRESS ANNOUNCEMENT
========================

On boot the room server posts its own public URL to a public topic on ntfy.sh:

  topic   rotruin-host-9f3c2a7b
  read    https://ntfy.sh/rotruin-host-9f3c2a7b/json?poll=1

It exists because a Render free service gets random characters appended to its
onrender.com address, so the address cannot be worked out from the service name
and had to be copied by hand. The message contains nothing except that URL.

  ANNOUNCE=off                 switch it off entirely
  ANNOUNCE_TOPIC=<name>        post somewhere else

It is one fetch call in server.js (announce()). Nothing else depends on it, and
the server runs identically without it.
